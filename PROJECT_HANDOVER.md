# PROJECT_HANDOVER – historisk reference

Denne fil bevares som kompatibilitetsindgang for ældre InvestViden-dokumentation.

Den fulde desktop-handover fra 2026-09-14/15 blev leveret i den sanitiserede `InvestViden-kode-snapshot-2026-09-15.zip` og blev brugt som kilde ved browseroverdragelsen.

Den levende og autoritative projektstatus vedligeholdes nu i:

1. `AGENTS.md`
2. `docs/todo.md`
3. `docs/handover.md`
4. `docs/decisions.md`
5. `docs/changes.md`

Historiske desktop-oplysninger må ikke uden videre omtales som aktuelle. `docs/handover.md` skelner mellem browserverificeret status og desktop-verificeret historisk status.

Vigtige sikkerhedsgrænser fra den historiske handover er bevaret i projektfundamentet: aktiv schema-2-database må ikke migreres uden ny udtrykkelig godkendelse, private kilder/databaser/secrets må ikke pushes til GitHub, og AI-output bliver først aktiv viden efter individuel menneskelig godkendelse eller korrektion.
